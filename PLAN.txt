Problem statement:

Build a Mini Issue Triage Dashboard using Next.js, NestJS, TypeScript, and any internal/local/free database option you prefer, such as PostgreSQL local, MongoDB Atlas free tier, Supabase free tier, Neon free tier, SQLite, or any internal DB setup available to you. Please do not use a paid database service.
The goal is to create a small internal tool where users can create, view, update, delete, search, and filter engineering issues. Each issue should have title, description, status, priority, category, optional assignee, createdAt, and updatedAt.
Please include:
NestJS backend with proper modules, controllers, services, DTOs, and validation
Next.js frontend dashboard
CRUD APIs
Search and filters
Dashboard summary cards
Database persistence
README with setup instructions, DB instructions, env variables, and API endpoints
Optional if you finish early: pagination, sorting, seed data, Docker Compose, or basic tests.
This should be completed within one working day. The goal is not to overbuild it, but to show clean architecture, practical full-stack thinking, and good TypeScript quality.

AUTHENTICATION SYSTEM ->

AUTH FLOW:

SIGNUP:
- validate req body
- hash password using bcrypt
- store user

LOGIN:
- validate credentials
- generate JWT access token

PROTECTED ROUTES:
- JwtAuthGuard validates token
- request.user injected automatically

FRONTEND AUTH:
- token stored in httpOnly cookie OR localStorage
- persist login after refresh
- protected dashboard routes
